Morse code gaze-tracking login

A desktop login with no password to type. The system first recognizes your face on the webcam, then you enter your code in Morse by blinking or looking in patterns. The decoded code is matched against your stored credentials. We built it to explore accessible, alternative ways to authenticate.

How it works

  1. Register: the app captures face samples from the webcam and trains a recognition model for the new user.
  2. Verify identity: at login, OpenCV's LBPH face recognizer checks the face against registered users before going further.
  3. Enter the code in Morse: dlib's facial landmark detection tracks the eyes, and blink or gaze patterns become dots and dashes.
  4. Decode and match: the Morse sequence is decoded and compared with the user's stored credentials.
  5. Notify: a Telegram bot sends a login notification or alert.

Features

  • Face recognition login with OpenCV's LBPH recognizer.
  • Gaze and blink Morse input using dlib's 68-point facial landmarks.
  • Mouse-click Morse input as an alternative mode, using timed clicks instead of eye tracking.
  • User registration that captures face samples and retrains the model.
  • Telegram bot alerts for login events, including photo attachments.
  • Desktop GUI in Tkinter for the registration and login flows.

Privacy by design

No face data or secrets in the repo.

Face samples, the trained model (trainer.yml) and user records are created locally when someone registers and are never committed. Bot tokens and other credentials live in a gitignored config.py.
